# 요술나무 오르기 — 기획 한 장 (초안)

> 장르: 세로 스크롤 등반 액션 (모바일 세로 화면).
> 특정 기존 게임의 재현이 아니라, 이 프로젝트의 요술나무 세계관으로 새로 설계한 게임이다.

## 분위기
- **파스텔 + 따뜻한 감성**: 크림·복숭아·연분홍·민트·연보라. 노을빛 햇살, 부드러운 그림자, 동글동글한 형태.
- 무섭거나 공격적인 요소 없이, 떨어져도 "폭신" 하고 다시 일어나는 다정한 톤.

## 이야기 (컷신 3~4컷)
1. 숲 마을의 꼬마 **토리**(도토리 모자를 쓴 아이)가 밤하늘에서 요술나무 꼭대기로 떨어지는 별똥별을 본다.
2. "별 열매가 열리면 소원이 하나 이뤄진대." 할머니의 이야기.
3. 토리는 작은 가방에 물병을 챙겨 요술나무 밑동으로 간다.
4. 꼭대기에서 별 열매를 찾으면, 아픈 숲 친구들을 낫게 해 달라고 빌기로 한다.

## 플레이
| 요소 | 내용 |
|---|---|
| 목표 | 나무를 타고 최대한 높이 올라가기. 높이(m)가 점수, 구간마다 이야기 컷 해금 |
| 조작 | 왼쪽 아래 ◀ ▶, 오른쪽 아래 점프. 덩굴 앞에서 ▲▼ 로 오르내리기 |
| 지형 | 가지 발판, 오르내리는 덩굴, 흔들리는 덩굴 그네, 통통 튀는 버섯, 잎사귀 엘리베이터 |
| 방해 | 굴러오는 솔방울, 낮잠 자다 뒤척이는 애벌레, 옆으로 미는 꽃가루 바람 — 닿으면 아래 발판으로 미끄러짐 |
| 보상 | 마나 이슬(모으면 꾸미기 해금: 토리 모자·가방 색), 반딧불 체크포인트(50m마다) |
| 실패 | 목숨 없음. 떨어지면 마지막 체크포인트에서 재시작, 최고 높이 기록 저장 |

## 구성 (1차 목표: 플레이 가능한 프로토타입)
- 구간 1 "뿌리 마을" 0~100m → 구간 2 "꽃잎 층" 100~250m → 구간 3 "별빛 가지" 250m~ (무한 생성)
- 발판·덩굴·방해물은 규칙 기반으로 위쪽에 계속 생성 (손으로 그린 맵 없음)

## 아트 목록 (kie.ai Sunburst)
- `char_tori` 주인공 시안 → 확정 후 같은 그림을 기준으로 이미지→이미지로 동작별 그림(서기·달리기·점프·오르기)
- `bg_climb` 세로로 이어지는 요술나무 줄기·하늘 배경
- 이후: 가지 발판, 덩굴, 버섯, 솔방울, 애벌레, 반딧불, 마나 이슬(기존 재사용), 컷신 4장

## 기존 "키우기" 프로토타입
- 그대로 두고, 등반 게임이 메인이 되면 정리한다 (예: 휴식 모드로 남기기).
