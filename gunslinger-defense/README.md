# 황야의 총잡이 (Gunslinger Defense)

세로 화면 **직접 조준 슈팅 디펜스** 게임. 망루 위 총잡이가 골짜기로 몰려오는 무법자들을 저격해 20웨이브를 버틴다.
기획: `docs/design.md`

## 바로 해 보기
- `index.html` 한 파일짜리 게임이다(라이브러리 없음, 그림·소리 모두 코드로 만든다). 브라우저로 열면 된다.
- 휴대폰에서는 세로로 들고 하는 게 기본이다. PC에서는 마우스 끌기 / 방향키로 조준하고, Space 발사, Z 스코프, R 장전, F 난사.

## 조작
| 동작 | 방법 |
|---|---|
| 조준 | 화면 어디서나 끌기 (스코프 중에는 더 섬세하게) |
| 발사 | 손 떼기 |
| 스코프 | 왼쪽 아래 버튼 |
| 완벽 장전 | 장전 중 막대가 노란 칸에 있을 때 탭 |
| 난사 | 오른쪽 아래 버튼 (처치 22번으로 충전) |

## 수치 바꾸기
`index.html` 위쪽의 `CFG`(총·체력), `ENEMY`(적), `CARDS`(기술 카드), `PERMS`(영구 강화), `buildWave`(웨이브 구성)에 모여 있다.
바꾼 뒤에는 자동 플레이로 확인한다:

```bash
node tools/playtest.js 9            # 9판 자동 플레이 결과(도달 웨이브, 명중률 등)
node tools/playtest.js 3 <폴더>      # 결과 + 타이틀/전투/스코프/레벨업 스크린샷
```
